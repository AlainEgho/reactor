Fission — Privacy policy

Applies to the Fission game on Android, iOS and the web (alainegho.github.io/reactor). Last updated 2 November 2026.

The short version: Fission has no accounts, no analytics, no advertising and no servers of its own. Everything you type or earn in the game stays on your device. We do not collect, receive, sell or share any personal data.

What the game stores on your device

Fission keeps the following in the app's local storage (and, on the web, in a first-party cookie) so that the game remembers you between sessions:

ItemWhat it is
NameThe name you type on the sign-in screen. It is only used to greet you on the menu. It can be anything; it does not have to be your real name.
ProgressLevels cleared, stars, scores, streaks, which level set is selected, and whether you have seen the How to play guide.
PreferencesSound and music on or off, the on-screen control layout, Christmas mode, and any access codes you have entered.
Level fileIf you choose to load a Classic level file from your device, a copy is kept locally so it is there next time. You can forget it from the menu at any time.

None of this ever leaves your device. Signing out from the menu clears the name; uninstalling the app (or clearing the site's data in your browser) removes everything.

What the game sends over the network

  • Level data. The game loads its level file (gamedata.txt) from the same place the game itself is served from. In the apps it is bundled inside the app, so nothing is downloaded.
  • Fonts. The game's two typefaces are fetched from Google Fonts (fonts.googleapis.com and fonts.gstatic.com). Like any web request, this lets Google see your IP address and the browser's standard request headers. Google's handling of these requests is described in the Google Fonts privacy FAQ. No identifier from the game is included in the request.
  • Hosting. The web version is hosted on GitHub Pages. GitHub may log IP addresses of visitors for security and operational purposes under the GitHub privacy statement. We do not have access to any such logs.

The game makes no other network requests. It does not phone home, does not report crashes, and does not contain any third-party SDK.

Permissions (Android)

  • INTERNET — to fetch the fonts described above.
  • VIBRATE — short haptic taps when Iso digs, lands or wins. Can be ignored by turning vibration off in your system settings.

The game does not request access to your location, contacts, camera, microphone, photos, files (other than a level file you explicitly pick) or any device identifier.

Children

Fission is suitable for all ages and is designed with young players in mind. Because the game collects no personal information from anyone, it collects none from children. The name field is a nickname that stays on the device; we recommend children do not type their full real name, although nothing would be done with it if they did.

Purchases and advertising

Fission is free, has no in-app purchases, and shows no advertising.

Your choices

  • Sign out from the menu to clear your name from the device.
  • Use "Forget this file" on the menu to delete a loaded level file.
  • Uninstall the app, or clear the site's data in your browser, to remove every trace of the game.

Changes

If the game ever starts handling data differently — for example if an online leaderboard were added — this page will be updated first and the date at the top will change. The source of the game and of this page is public at github.com/AlainEgho/reactor, so any change is visible in its history.
